# Ironclad — Site

Documentation and marketing/landing site for **Ironclad**: sender-constrained
session tokens powered by DPoP + DBSC + mTLS middleware and SDKs.

## Stack

- **Next.js** 16.4.6 (App Router, Turbopack)
- **React** 19.3
- **TypeScript** 7.0.2
- **Deployment**: Vercel

## Content structure

- `app/` — Next.js App Router pages (landing, docs shell)
- `content/guides/` — long-form technical guides
- `content/blog/` — engineering blog posts
- `content/changelog/` — release notes and changelog

## Status

> **Scaffold only — site ships in Phase 5 (Sprint 5).**

This repository currently contains a minimal Next.js skeleton and empty content
directories. No dependencies are installed (no lockfile, no `node_modules`) and
no content has been written yet.
